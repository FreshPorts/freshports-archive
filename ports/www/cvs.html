How to CVS for FP2

Freshports uses CVS for source control. If you don't already know everything about CVS then this book is a killer introduction. It's freely available in digital format and worth buying the treeware version too.

To access FP2's CVS repository, You'll want to set your CVSROOT to something not entirely unlike:

:pserver:XXXXXX@cvs.freshports.org:/home/cvs-scripts
as described in the red-bean book's Accessing A Repository section. Obviously you want to replace 'XXXXXX' with your username.

FP2 also has web access available to it's CVS repository, for your convenience at:

http://fp2.unixathome.org/cgi-bin/cvsweb.cgi.
